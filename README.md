# 报销云 · 财务报销管理系统

一套**可演示**的财务报销管理系统：员工在线提交发票与报销信息，财务在线审核，出纳一键打款，管理员全程管理与审计。全流程状态实时可见、操作留痕，并内置了**管理员智能体**（管理后台对话 + DSH 智能体预设）。

---

## 一、技术栈

- **纯 Node.js 内置模块**，零第三方依赖，无需 `npm install`
- 内置 **SQLite**（`node:sqlite`，Node ≥ 22.5）持久化
- 内置 `crypto`（scrypt）做密码散列；`http` 做服务；`child_process` 驱动查询
- 前端为原生 **HTML/CSS/JS 单页应用**，无框架
- 智能体直连 **DeepSeek 官方 API**（默认模型 `deepseek-v4-flash-vision-exp`）

## 三、角色与职责（访问矩阵）

| 角色 | 可见数据 | 可执行动作 |
| --- | --- | --- |
| 员工 | 仅**自己**的申请（全部状态，含已撤回/已驳回） | 新建、编辑、撤回、驳回后重新提交 |
| 财务审核 | **所有**员工，但**排除「已撤回」**（待审核/已通过/已驳回/已打款） | 仅对待审核：审核通过 / 审核不通过（必须填原因） |
| 出纳 | 仅「已通过（待打款）」与「已打款」 | 对待打款：打款 |
| 管理员 | **全部**（含已撤回），业务只读 | 账号管理、操作审计、报销总览、导出 CSV、智能问答 |

**职责分离（不可越权）**：只有财务能审核、只有出纳能打款、只有员工能提交/改/撤、只有管理员能管理账号/审计/对话/导出；每个接口都做**角色 + 状态**双重校验，其它角色一律 403。

---

## 四、状态与流程

```
待审核 → 审核通过 → 已打款
   └─→ 审核不通过 ──（员工修改后重新提交）──→ 待审核
   └─→ 已撤回（员工在待审核时撤回，财务不可再审核）
```

状态以彩色徽章 + 统计卡片 + 筛选页签展示；前端每 3 秒轮询刷新，状态变化以 Toast 即时提醒。

## 五、核心业务与边界处理

- **金额**：必须 >0，单笔上限 1,000 万，前后端双重校验。
- **发票图片**：类型（PNG/JPG/GIF/WebP）、大小（≤10MB）、**真实图像魔数校验**，伪造/非图片拒绝；**上传合法图片**方可创建记录（失败不落库）。
- **重复提交**：实时 + 提交后双重检测“同人、同金额、同内容的进行中申请”，给出提醒（不硬拦，允许用户判断）。
- **重复打款 / 重复审核**：服务端幂等拦截（已打款/已驳回/已通过不可重复操作）。
- **撤回**：仅待审核可撤一次；撤回后财务不可审核、不可重复撤。
- **修改/重提**：仅待审核或已驳回可改；已驳回修改后自动回到待审核。
- **越权**：员工看不了他人；员工不能审核/打款；财务不能打款；出纳不接触评审信息。
- **账号**：停用即禁止登录并踢下线；不能删/停自己；不能删或降级最后一名启用的管理员。
- **失败处理**：登录态过期自动回登录页；上传失败不创建记录；接口返回明确错误。

## 六、管理员后台（admin）

- **报销总览**：全量只读，按状态筛选、搜索；**一键导出 CSV**（UTF-8 BOM，Excel 直接打开；仅管理员）。
- **账号管理**：新增/编辑、改姓名与角色、重置密码、启用/停用、删除（带守卫）。
- **操作审计**：按操作人 / 动作 / 时间筛选的全局日志（账号、登录、报销流程事件），操作人姓名冗余存储，删除账号后仍可读。

---

## 七、管理员智能体

系统提供**两种**形态的管理智能体，共用同一份只读查询（`admin-query.js`），数据口径一致：

1. **管理后台「智能问答」面板**（嵌入业务网页）
   - 管理后台 → 智能问答，气泡式对话，直连 DeepSeek 真实模型。
   - 凭借内置只读查询回答：报销统计/明细/审计/账号/系统运行状态。
   - **密钥与模型配置化**：智能问答 → 配置，填写 API Key / 模型 / Base URL，支持“测试连接”；密钥仅存服务端、不回显。
2. **DSH Agent 预设 `admin-helper`**（智能体开发环境）
   - 轻量化：仅 persona + 一个持久 shell 工具，去掉多余插件。
   - 在 DSH（`http://127.0.0.1:3080`）新建会话选「管理员智能助手」即可对话查询。

> 两个智能体都**只读**，绝不修改报销数据。

## 九、配置说明（`config.json`）

```json
{
  "deepseekApiKey": "",
  "deepseekModel": "deepseek-v4-flash-vision-exp",
  "deepseekBaseUrl": "https://api.deepseek.com",
  "seedDemoData": false
}
```

- `deepseekApiKey` / `deepseekModel` / `deepseekBaseUrl`：智能体对话配置，支持 **环境变量覆盖**：`DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` / `DEEPSEEK_BASE_URL`。
- `seedDemoData`：`true`=启动时注入示例报销单；`false`=空库开始（默认 true，当前为 false）。
- 密钥**仅存服务端**，前端拿不到明文；请在管理后台「智能问答 → 配置」中填写，**不要对外提交/外传** `config.json`。

## 十二、注意事项 / 安全

- 上传的发票图片需**登录鉴权**（`?token=`），未登录不可访问。
- 报销导出仅限**管理员**；财务/出纳按职责收窄可见范围（财务不看已撤回、出纳只看待打款/已打款）。
- `config.json` 含敏感密钥，请勿提交到版本库或外传。
- 本系统为演示/教学用途，生产环境需补充：HTTPS、更严格的会话策略、审计告警、备份等。
